# L-041, L-043 (point 4), L-044 : fait dans la place DEV (2026-11-07)

Tout est construit sans script, avec les noms d'Ironix acceptés par Clément. Vérifié en Edit : `UI_HUD` 13/13, `UI_WeaponShop` 9/9 et `UI_AuraShop` 11/11 (règles de `Contract/UI.luau`), `BB_Upgrade` 3/3 et `BB_StoreInfo` 4/4. Pas de Play.

- **`UI_WeaponShop`** (bandeau orange, sans onglets) et **`UI_AuraShop`** (bandeau rose, `Tabs.AurasTab` et `Tabs.TrailsTab` à droite) : cachés (`Enabled = false`), au style de la Boutique Robux. Grille de cartes : 3 colonnes sur PC et portable, 2 sur téléphone. Boutons d'au moins 44 px ; rien ne déborde à 1920, 1366, 750 et 667 px de large. `BuyButton` (vert, icône cash + `Price`) et `EquipButton` (bleu) sont au même endroit : le code n'en montre qu'un.
  - Armes : `EquipButton` porte son propre texte (« Equip »), pour que le code y écrive « Equipped ». Échantillons `ItemName` et `Power` en casse mixte, comme le code les écrit.
  - Auras : `EquipButton` sans texte propre ; le code écrit dans son TextLabel `EquipLabel` (« EQUIP » en capitales, donc « UNEQUIP »). Échantillons `ItemName` en capitales.
  - Listes : `Template` caché, plus des exemples `Preview_*` (7 outils, 6 auras) que le code doit supprimer au branchement.
  - `Icon` des armes : le code n'y touche pas, donc toutes les lignes ont l'icône marteau du Template. **Proposition pour Ironix** : poser l'icône de chaque outil quand les rendus MOD-027 existeront.
  - Onglet ouvert : rien ne le distingue, parce que le code ne touche pas au style. **Proposition** : un enfant `Selected` par onglet, dont le code changerait la visibilité.
- **`BB_Upgrade`** (`ReplicatedStorage/Assets/UI`) : `UpgradeName`, `Level`, `Price`, au style de `BB_Item`, avec `SizeOffset (0, 0.5)` (bas au point d'accroche) et `MaxDistance` 40. `UpgradePoint` n'est pas posé : il n'existe pas encore de modèle tapis ou banc de Clément (MOD-016).
- **`Cooldown`** : TextLabel dans `UI_HUD.ReturnBaseButton`, pastille sombre « 84s » sur l'icône maison, `Visible = false` (le code la montre pendant la recharge).
- **`BB_StoreInfo`** : panneau sombre arrondi, `StoreName` en haut, puis `HP` (rouge clair), `Damage` et `Speed` (couleurs d'exemple, le code les remplace). Taille studs + pixels, `MaxDistance` 80, bas au point d'accroche.
- **`InfoPoint`** : un Attachment dans la boîte `Bounds` de chacun des 12 magasins, à 0,8 stud devant la façade. Il est au-dessus de l'enseigne quand elle est juste sur la vitrine, et au-dessus de la vitrine pour la Salle des coffres, dont l'enseigne est très haute. Rien d'autre n'a bougé dans les magasins. **Attention** : les scripts de construction des zones (`tools/clement/...`) ne posent pas `InfoPoint` ; relancer une zone le supprime.
- **`BB_WindowHP`** : `StudsOffset` passé de 3,7 à 5,45, pour que la barre reste juste au-dessus des vitres du gabarit ×1,5 (18 × 10,5).
