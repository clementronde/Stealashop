# AUTO COLLECT (`AutoCollect`) — fiche gamepass

Statut : **proposition, à valider par Clément** (2026-11-21). Rien créé sur Roblox.

| Champ | Contenu |
|---|---|
| Clé | `AutoCollect` (`Order = 4`) |
| Nom | **AUTO COLLECT** (inchangé) |
| Effet exact | L'argent des plaques `CollectPad_xx` est encaissé **chaque seconde, où que soit le joueur sur le serveur** (DisplayService.HasAutoCollect). Ne crée aucun argent en plus : il évite seulement les allers-retours. |
| Équilibre | L'argent des plaques **n'est pas volable** (DisplayService) : le pass ne protège rien, c'est du pur confort. Aucun effet sur le vol entre joueurs. Le pass le plus « inoffensif » de la gamme. |
| Prix actuel | 199 R$ |
| **Prix proposé** | **99 R$** : notre **pass d'appel** (le benchmark montre un premier achat à 49–99 partout : Auto Collect à 49 chez Steal A Pet And Ride It). Comme il ne donne pas d'argent en plus, il peut être bon marché sans rien casser. Variante : 149. |
| Description (page Roblox) | `Your cash collects itself, even when you're far from your shop. Forever!` |
| Ligne de carte | `Cash collects itself, anywhere` (inchangée) |
| Place dans la boutique | Gamepasses, après VIP. Étiquette proposée : « CHEAP! » ou rien (à toi de voir). |
| Icône | `UI_Icon_GP_AutoCollect` (existe : portefeuille violet avec billets). Concept famille : **aimant rouge qui attire des billets** (le symbole le plus lisible du genre pour « auto collect »), ou garder le portefeuille ; médaillon jaune `FFC928`. |
